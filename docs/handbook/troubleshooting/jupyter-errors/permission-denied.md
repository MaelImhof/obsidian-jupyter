# Permission Denied

This error is encountered when the *Jupyter for Obsidian* plugin does not have sufficient permission to run Python and start Jupyter.

1. Check that you have sufficient permissions to start Jupyter yourself from a terminal.

1. For Unix-based systems (Linux, macOS), check that the provided Python executable path points to a file that is marked as executable.

If you need more help, please [open a ticket](../index.md#opening-a-ticket).
