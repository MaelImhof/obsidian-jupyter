---
title: Install Jupyter for Obsidian
---
Before configuring or using the plugin, you need to install it in your Obsidian vault.

As of now, Jupyter for Obsidian is **still in beta**, hence it is not yet available in the [Obsidian community plugins list](https://obsidian.md/plugins). To install the plugin, you need to use a special Obsidian plugin called [BRAT](https://github.com/TfTHacker/obsidian42-brat).

Here is how to proceed :

1. Backup your vault!
2. Install the [BRAT](https://github.com/TfTHacker/obsidian42-brat) plugin from the Obsidian community plugins.
3. Go in BRAT settings and click `Add Beta plugin`
   
   ![[add-beta-plugin.png]]
4. Use `https://github.com/MaelImhof/obsidian-jupyter` as the URL, tick `Enable after installing the plugin` and click `Add Plugin`.
   
   ![[popup-add-plugin.png]]
5. Voilà! The plugin should now be installed in your vault. Use it as a normal plugin and **[[get-in-touch|provide feedback]]** about the beta.
   
   ![[setup-done.png]]

Now that you have the plugin installed, you can start configuring it and using Jupyter inside of Obsidian directly.
