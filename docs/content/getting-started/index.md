Welcome, and thank you for your interest in Jupyter for Obsidian !

Jupyter for Obsidian is an Obsidian plugin that allows you to transparently open, edit and run `.ipynb` files inside of Obsidian directly.

![[jupyter-inside-obsidian.png]]

This getting started guide aims to show you everything you need to know to set up the plugin in your vault for your particular use-case. It is intended to be followed as a linear process, from installation to configuration and usage.

If you have any questions, please skip right through the [[get-in-touch|Get in touch]] page to open an issue on GitHub or ask your question on Discord.

Without further ado, jump into the **first part of this guide, the [[installation|installation]] of the plugin**.
